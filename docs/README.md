## Documentation rules

- Keep project status accurate and update it when implementation or design decisions change.
- Update `HANDOFF.md` whenever development reaches a meaningful stopping point.
- Preserve experiment measurements and distinguish measured results from interpretations.
- Record important design decisions rather than relying on conversation history.
- Do not describe experimental functionality as implemented production functionality.
- Keep personal test media and private data out of Git.
